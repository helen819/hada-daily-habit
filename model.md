## `--target-pydantic-version` {#target-pydantic-version}

Target Pydantic v2 minor version for generated model config.

The `--target-pydantic-version` flag controls which ConfigDict key is used for field-name population when generating Pydantic v2 models with `--allow-population-by-field-name`:

- **`2`** (default): Uses `populate_by_name=True` — compatible with Pydantic 2.0 through 2.10.
- **`2.11`**: Uses `validate_by_name=True` — the replacement introduced in Pydantic 2.11, where `populate_by_name` is deprecated. Also emits `validate_by_alias=True` when alias population is required.

Use `--target-pydantic-version 2.11` if your project pins Pydantic 2.11 or later and you want to eliminate the `populate_by_name` deprecation warning in generated code.

**See also:** [`--allow-population-by-field-name`](model-customization.md#allow-population-by-field-name), [`--output-model-type`](model-customization.md#output-model-type)

!!! tip "Usage"

    ```bash
    datamodel-codegen --input schema.json --output-model-type pydantic_v2.BaseModel --allow-population-by-field-name --target-pydantic-version 2.11 # (1)!
    ```

    1. :material-arrow-left: `--target-pydantic-version` - the option documented here

??? example "Examples"

    **Input Schema:**

    ```json
    {
      "$schema": "http://json-schema.org/draft-07/schema#",
      "title": "Pet",
      "type": "object",
      "required": ["id", "name"],
      "properties": {
        "id": {
          "type": "integer"
        },
        "name": {
          "type": "string"
        },
        "tag": {
          "type": "string"
        }
      }
    }
    ```

    **Output:**

    === "Pydantic v2 (--target-pydantic-version 2)"

        ```python
        # generated by datamodel-codegen:
        #   filename:  pet.json
        #   timestamp: 2019-07-26T00:00:00+00:00

        from __future__ import annotations

        from pydantic import BaseModel, ConfigDict


        class Pet(BaseModel):
            model_config = ConfigDict(
                populate_by_name=True,
            )
            id: int
            name: str
            tag: str | None = None
        ```

    === "Pydantic v2.11+ (--target-pydantic-version 2.11)"

        ```python
        # generated by datamodel-codegen:
        #   filename:  pet.json
        #   timestamp: 2019-07-26T00:00:00+00:00

        from __future__ import annotations

        from pydantic import BaseModel, ConfigDict


        class Pet(BaseModel):
            model_config = ConfigDict(
                validate_by_name=True,
            )
            id: int
            name: str
            tag: str | None = None
        ```
